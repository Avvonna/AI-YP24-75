## 🧾 Описание проекта:
Этот проект направлен на разработку системы предсказания стоимости акций с использованием различных методов анализа данных, машинного обучения и глубокого обучения.

## 🎯 Цель проекта:
Создать инструмент для прогнозирования цен на ценные бумаги, который можно использовать для принятия информированных инвестиционных решений.

## ✅ Результаты:

- Получение данных из множества различных источников (см. [dataset.md](Stages/dataset.md))
- Разведочный анализ данных (подробнее в [1_Tickers_EDA.ipynb](Stages/1_Tickers_EDA.ipynb) и [1_EXOG_d_EDA.ipynb](Stages/1_EXOG_d_EDA.ipynb); выводы в [EDA.md](Stages/EDA.md))
- Построение базового решения - `ARIMA` на основе данных за последние 2 месяца, с автоподбором оптимальных параметров (подробнее в [2_Baseline.ipynb](Stages/2_Baseline.ipynb))
- Построение ML решения - `CatBoost` с предварительной автоматической генерацией признаков (лаги, MA/EMA, RSI, MACD, волатильность, статистики и пр.) (подробнее в [3_ML.ipynb](Stages/3_ML.ipynb))
- Построение DL решения - `LSTM` с использованием признаков, созданных ранее (подробнее в [4_DL.ipynb](Stages/4_DL.ipynb))

## 🚀 Запуск проекта:

## 🧩 Реализованные компоненты:

### 🖥️ Frontend (Streamlit)
Визуальный интерфейс для пользователей: загрузка данных, запуск прогнозов и анализ результатов через вкладки:
- `📁 Исторические данные`
- `🔮 Прогнозирование`
- `⚖️ Анализ результатов`

### ⚙️ Backend (FastAPI)
REST API для обработки запросов, запуска моделей и управления экспериментами.  
Документация доступна по адресу `/docs`.

### 🧪 Генерация признаков
- Классические временные признаки (лаговые значения, процентные изменения, моментум и др.)
- Скользящие показатели (MA / EMA, волатильность и др.)
- Индикаторы технического анализа (RSI, MACD, Bollinger Bands и др.)
- Статистические признаки (skew, kurtosis, квантили и др.)

### 📦 Модели прогнозирования
- `ARIMA` — базовое решение
- `CatBoost` — ML-модель
- `LSTM` — DL-модель

### 🐳 Контейнеризация (Docker Compose)
Обеспечена воспроизводимость и лёгкий запуск всех компонентов (frontend + backend)

### 🧪 Тестирование
Покрытие юнит-тестами некоторых сервисов и API-маршрутов
